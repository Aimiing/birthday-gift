# 生日电子盲盒

一个单文件的生日礼物网页：首页 → 三轮互动（其中第 3 轮揭晓真礼物）→ 一封写给他的信。

## 怎么打开

**双击 `index.html`** 即可用默认浏览器打开，不需要安装任何东西，也不需要联网。

想看手机上长什么样：按 `F12` 打开开发者工具，点左上角的手机图标切到设备模拟模式。

## 怎么改内容

用记事本或 VS Code 打开 `index.html`，找到这一行：

```js
const CONTENT = {
```

下面所有文案都在这个对象里，改引号中间的字就行：

| 字段 | 作用 |
| --- | --- |
| `brand` | 左上角那行小字（现在是「只给你一个人」） |
| `sender` / `receiver` | 首页的「来自」「收件人」 |
| `title1` / `title2` | 首页两行大标题 |
| `round1.cards` | 第 1 轮的三张卡片（`text` 里的 `\n` 表示换行） |
| `round2.question` / `options` / `answer` | 第 2 轮的题目、选项、正确答案 |
| `round2.answer` | 正确答案的**位置**，从 0 开始数（第一项填 `0`，第二项填 `1`） |
| `round3.giftName` / `giftDesc` | 真正送他的礼物名称和描述 |
| `final.letter` | 最后那封信的正文，`\n\n` 是空一行 |
| `final.sign` | 信的署名 |

改完保存，刷新浏览器就能看到。

## 怎么发给对方

**不要直接发 `.html` 文件** —— 微信不预览 html，手机上点开会提示「文件无法打开」。

正确做法是部署成网址，发链接过去。部署方式见项目根目录的说明，或直接找 Claude 帮你部署。

---

技术说明：单文件、零依赖、内联 SVG 插画、无外部图片。字体优先用系统宋体/黑体，联网时会尝试加载 Noto 思源字体，加载失败自动回退，不会白屏。
